This update restores straightforward library deletion and brings the remaining tools into the compact workspace.

- **My Library:** delete a filament, type, or brand directly from the tree, or delete one printer profile beside its selector. Both system and custom libraries are supported, with a scoped confirmation and backup.
- **My Library → Advanced library tools:** edit profile names/brands, change a selected group's brand, remove installed copies, repair AMS IDs, and review catalog repairs. Opens in the same window.
- **Add Filaments → Advanced import:** edit package names/brands, open legacy packages, select or skip duplicates, choose explicit destinations, and review imports. Opens in the same window.
- Program Files removal, mirroring, and AMS repair use separate administrator actions; ordinary editing needs no elevation.
- Maintenance keeps backups, Studio-update recovery, and diagnostics. The old-interface launcher is removed.
- Added dependency protection for custom presets, recent-AMS cleanup, stale-review protection, installed-catalog rollback, and clearer profile-selector labels.
- BFI and filament-library update notices remain supported, with session dismissal restored.

The [feature audit](https://github.com/Zataralee/Bambu-Filament-Importer/blob/v0.6.2/docs/WORKSPACE_FEATURE_AUDIT.md) maps every previous action to its current location. Validation uses isolated libraries and checks both themes and same-window navigation; no live filaments were deleted during testing.
