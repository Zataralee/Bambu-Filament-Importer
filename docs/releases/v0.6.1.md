This update organizes filament lists into expandable menus and adds recovery after Bambu Studio updates.

- Removed the test-copy/live-library switch and test-copy maintenance controls.
- **Add Filaments** and **My Library** now use **brand → type → filament** groups. Search reveals matching branches.
- **My Library** separates **Custom Library** from **Bambu System Library**. You can still select and edit profiles in either library.
- Selected tabs and tree entries keep a consistent highlight when the pointer or focus moves.
- Imports use **Bambu System Library** by default so Studio groups filaments by brand. An unchecked **Import into custom presets instead** option switches to the user library. Its tooltip explains update protection and Studio's long Custom list.
- BFI saves recovery points for imported system profiles and configuration. When Studio's version changes, BFI offers to restore saved imports. Choosing No retains the recovery point for later in Maintenance.
- Recovery merges saved imports into the updated catalog, keeps new Bambu profiles and custom presets, and preserves unrelated configuration and current filament-slot order. Studio must be closed. A safety backup and transactional rollback protect the restore.
- Recovery starts after the first successful snapshot in this version; files already lost before that snapshot cannot be recovered by version detection.
- New custom presets contain their inherited settings and have no system-parent dependency. A `(Custom)` suffix prevents name collisions with system presets. Existing profiles are not automatically moved or deleted.
- Application and filament-library update notifications remain enabled.

Validated with isolated custom/system import, tuning preservation, rollback, catalog-replacement, and grouping tests, plus the Studio 2.9.1 regression suite. No physical-printer tests were performed.
