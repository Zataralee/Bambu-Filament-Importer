The Compact workspace is now the main BFI interface, with the original application icon and a simpler flow from filament selection to installation. This release also fixes the import failure caused by repeated JSON settings in Bambu Studio 2.9.1.

### What's new

- **Add filaments:** search across downloaded manufacturers, choose products, printers, and nozzles together, then review changes before installing.
- **My library:** choose a product and its exact printer profile, search settings, and see where inherited values come from.
- **Maintenance:** library checks, missing coverage, backups and restores. Advanced rename, bulk removal, AMS repair, and legacy import tools remain available here.
- Automatic backups, stale-review checks, preserved custom tuning, and rollback on failed changes.
- An optional **Test copy** for trying changes separately from your live Studio library.

### Updates still reach existing users

Existing BFI installations can discover v0.6.0 using their normal update check. The stable release feed and Windows update ZIP naming remain compatible. Your managed manufacturer downloads, notification history, theme preference, and Studio profiles are retained.

The new interface checks both feeds at startup and from **Check for updates**. It shows separate notices for newer BFI releases, updates to downloaded filament libraries, and newly available manufacturers. Downloads require a user action. Downloading a library updates the available package; it does not overwrite installed profiles or custom tuning.

### Download

Use **Bambu-Filament-Importer-v0.6.0-win-x64.zip** for the full portable Windows package, or the standalone **BambuFilamentImporter.exe**. Close other BFI windows before launching. Close Bambu Studio before applying live profile changes.
